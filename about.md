Hello! My name is **Serdar Kara**, and I am studying Computer Engineering at Necmettin Erbakan University in Konya. I enjoy building practical desktop applications, interactive web tools, and working on hardware-software integration projects. Outside of coding, I have a strong interest in automotive mechanics, vehicle diagnostics, and simulation games.

---

### 💻 Highlighted Projects & Coursework
Here are a few projects I have worked on during my studies:

* **Algorithm Visualization Tools:** Developed interactive web applications using JavaScript and HTML/CSS to visually demonstrate graph algorithms (Dijkstra, Bellman-Ford, Prim, Kruskal) and data compression techniques (Huffman Encoding, LZW).
* **Desktop Applications with C++ & Qt:** Built a complete Library Management System integrated with an SQLite database, as well as a 2D interactive game utilizing Qt timers and UI components.
* **Automotive Telemetry & Hardware:** Worked on reading and analyzing vehicle diagnostic data through the OBD2 port using microcontrollers and CAN Bus modules.
